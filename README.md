# Personal Portfolio

Portfolio personnel statique de Nour El Houda Karray, construit avec HTML, CSS et JavaScript.

Il présente le parcours, les compétences, l’expérience, les manifestations, les passions, un quiz et les projets GitHub : DocIA, Mission Management Platform, JavaFX Drawing App et HR Analytics Data Warehouse.

## Ouvrir localement

Ouvrir index.html dans un navigateur, ou lancer :

~~~powershell
python -m http.server 8000
~~~

Puis visiter http://localhost:8000.

Le site peut être déployé directement avec GitHub Pages.
